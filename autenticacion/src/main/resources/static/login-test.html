Inicio de sesión - Firebase Auth (Spring Boot)



Token:




  

  
Recuperar contraseña (Firebase, no pasa por el backend)

  
  
  


  

  
Crear usuario (POST /usuarios)

  
  
  
  
  


  

  
Asignar rol (POST /usuarios/:uid/rol — requiere token de admin arriba)

  
  
  
  


  

  
Consultar usuario (GET /usuarios/:uid — requiere token de admin arriba)

  
  
  


  

  
Buscar usuario por correo (GET /usuarios/por-correo?correo=... — requiere token de admin arriba)

  
  
  


  

  
Deshabilitar / habilitar / eliminar / revocar tokens (requiere token de admin arriba)

  
  
  
  
  
  


  

  
Eliminar TODOS los usuarios (DELETE /usuarios — requiere token de admin arriba)

  
Accion irreversible. Pide confirmacion antes de llamar al backend.

  
  


  

  
Carga masiva por CSV (POST /usuarios/carga-masiva — requiere token de admin arriba)

  
Formato del archivo: email,password,rol (una fila por usuario, "rol" puede ir vacío)
